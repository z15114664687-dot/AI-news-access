AI 情报系统：信息获取到展示工作流

覆盖采集配置、Gemini Google Search grounding、链接解析、SQLite 存储、Next.js API、React 展示、报告生成和静态导出。

Standalone HTML · 可本地离线打开
信息获取 Gemini API + Google Search grounding 搜索实时网页并输出结构化 JSON。
链接校验 sourceUrls 校验 URL；linkResolver 通过本地 CDP/浏览器解析真实原文。
数据存储 better-sqlite3 写入本地 SQLite：signals、sources、collection_runs、reports。
页面展示 Next.js API 提供数据，React Dashboard 渲染卡片、矩阵、地图和采集状态。
离线输出 static:export 从 SQLite 或样本 JSON 导出静态 HTML 快照。
